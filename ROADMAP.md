# Roadmap

## 0.1 - Foundation

- RSS and Atom ingestion
- deterministic URL/title deduplication
- company and alias matching
- transparent confidence scoring
- structured Python data models
- unit tests and documentation

## 0.2 - Better matching

- configurable alias dictionaries
- domain/source weighting
- multilingual text normalization
- fuzzy matching as an optional extension
- explainable match evidence

## 0.3 - Production-oriented tooling

- pluggable feed adapters
- persistence interfaces
- batch processing
- CLI commands
- benchmark fixtures
- CI and release automation

## Non-goals

This project is not a trading system, investment adviser, brokerage interface, or recommendation engine. It does not provide buy/sell signals.
